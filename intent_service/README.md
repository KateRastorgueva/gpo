# Классификатор тем вопросов

Сервис с двумя движками. Переключатель — в админке: **Управление → Система →
Классификатор тем** (сохраняется в настройках, применяется к следующему вопросу).

## Движки

### `kate` — модель Кати (по умолчанию)

Модель Кати ([KateRastorgueva/Chat-bot](https://github.com/KateRastorgueva/Chat-bot/tree/main/%D1%87%D0%B0%D1%82%20%D0%B1%D0%BE%D1%82)):
`cointegrated/rubert-tiny2` + небольшой слой сверху, дообучена на 3255 вопросах.
По тексту вопроса называет одну из **24 студенческих тем** (стипендия, общежитие,
ГПО, поступление…). Сама на вопросы не отвечает.

### `helpdesk` — TF-IDF по базе Help Desk ТУСУР

Альтернативный движок из проекта `tusur_bot`: TF-IDF (1–2 грамма) +
логистическая регрессия, обучен на 99 000 вопросах Help Desk. Знает **22 темы
IT-сервисов** ТУСУР («Личный кабинет», «Журнал посещаемости», «Облачное
хранилище», «Бронирование помещений», «Генератор ОПОП»…). На отложенной выборке
датасета — **top-1 100%, top-5 100%** (9 862 вопроса, пересечений с train нет).

Таксономии движков **не пересекаются**: у `kate` — студенческие темы, у
`helpdesk` — сервисы. Поэтому движок выбирается переключателем, а не заменяет
модель Кати; в админке показываются темы активного движка.

Артефакт `models/helpdesk_tfidf.npz` (~0,2 МБ) — только числа и строки (словарь
терминов, idf, веса, классы). Инференс считается на numpy в `helpdesk.py`,
поэтому версия scikit-learn в контейнере ни на что не влияет.

Переобучение (нужны pandas, scikit-learn):

```bash
python scripts/train_intent_helpdesk.py \
    --dataset path/to/tusur_bot/checkpoints/dataset.csv \
    --out intent_service/models/helpdesk_tfidf.npz
```

## Запуск

```bash
docker compose --profile intent up -d --build intent
```

Сборка один раз скачивает ~120 МБ весов модели Кати (сверяются по sha256) и
токенизатор. Контейнер занимает около 1 ГБ на диске и до ~600 МБ памяти
(ограничено в compose).

Дальше в админке: **Управление → Система → Классификатор тем** включить
переключатель. Порог уверенности и адрес сервиса (по умолчанию
`http://intent:8000`) — в «Настройках → Классификатор тем».

## API

- `GET /health` — состояние движков: `ok`, `error`, `categories` (для `kate`) и
  `engines: [{name, loaded, error, categories}]`.
- `POST /classify` `{"text": "Как получить стипендию?", "engine": "kate"|"helpdesk"}`
  → `{"category": "stipendiya", "label": "Стипендия", "confidence": 0.93,
  "candidates": [...], "engine": "kate"}`. Без `engine` — `kate`.

## Ограничения

- Темы «не по теме» ни в одном движке нет: вопрос про погоду всё равно получит
  одну из тем, обычно с низкой уверенностью. Для фильтра посторонних вопросов
  нужен отдельный класс `offtopic` (следующий шаг).
- `helpdesk` отвечает только про сервисы: на «Как оформить академический
  отпуск?» он выдаёт «Облачное хранилище» с низкой уверенностью — такие вопросы
  должен брать `kate`.
