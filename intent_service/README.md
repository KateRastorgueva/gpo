# Классификатор тем вопросов

Модель Кати ([KateRastorgueva/Chat-bot](https://github.com/KateRastorgueva/Chat-bot/tree/main/%D1%87%D0%B0%D1%82%20%D0%B1%D0%BE%D1%82)):
`cointegrated/rubert-tiny2` + небольшой слой сверху, дообучена на 3255 вопросах.
По тексту вопроса называет одну из 24 тем (стипендия, общежитие, ГПО, поступление…)
и уверенность от 0 до 1. Сама на вопросы не отвечает.

Отдельный контейнер, чтобы PyTorch не раздувал образ backend. Backend спрашивает
тему у каждого нового обращения и пишет её в журнал запросов; если сервис
выключен или недоступен, всё работает как раньше, просто без темы.

## Запуск

```bash
docker compose --profile intent up -d --build intent
```

Сборка один раз скачивает ~120 МБ весов (сверяются по sha256) и токенизатор.
Контейнер занимает около 1 ГБ на диске и до ~600 МБ памяти (ограничено в compose).

Дальше в админке: **Управление → Классификатор тем** включить переключатель.
Порог уверенности и адрес сервиса (по умолчанию `http://intent:8000`) там же.

## API

- `GET /health` — загружена ли модель, список тем.
- `POST /classify` `{"text": "Как получить стипендию?"}` →
  `{"category": "stipendiya", "label": "Стипендия", "confidence": 0.93, "candidates": [...]}`.

## Ограничения

- Темы «не по теме» в модели нет: вопрос про погоду всё равно получит одну из 24 тем,
  обычно с низкой уверенностью. Для фильтра посторонних вопросов модель нужно
  дообучить с отдельным классом `offtopic` (следующий шаг).
- Точность на наших реальных вопросах ещё не измерена.
